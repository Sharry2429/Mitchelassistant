# Mitchelassistant Autopilot

This directory contains the autonomous bug-finder and efficiency loop modeled on `karpathy/autoresearch`.
It is designed to make scoped, repeatable improvements to the repo without breaking existing functionality or experiencing scope creep.

See [program.md](program.md) for the steering document.
The offline deterministic scorer is [check.py](check.py).
Experiments and improvements are logged in [experiments.jsonl](experiments.jsonl).
