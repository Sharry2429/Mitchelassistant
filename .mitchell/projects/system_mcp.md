# System-MCP

## Overview
This project contains the Mitchell Assistant / System-MCP codebase. It leverages Python and various system integrations (like the Kokoro-ONNX TTS engine and Android MCP).

## Current Status
- TTS engine (Kokoro-ONNX int8) is integrated into `system_mcp.windows.tts`.
- Working on expanding Mitchell's capabilities and context retention.
